GitHub : mise en ligne et sauvegarde

Mettre l’application en ligne

L’application crée le dépôt sur votre compte GitHub, y dépose ce fichier, active GitHub Pages et vous donne l’adresse à partager avec les apprenants. Les TP enregistrés iront dans le même dépôt.

  1. Créer un jeton (une seule fois) : ouvrir la page GitHub, connectez-vous, descendez en bas et cliquez sur Generate token, puis copiez le code qui commence par ghp_.
  2. Collez-le ci-dessous, choisissez le nom du dépôt, puis cliquez sur Mettre en ligne.

    Réglages avancés de la sauvegarde des TP

    Les TP sont enregistrés dans le dossier tps/ du dépôt. Sans jeton, l’application peut seulement lire les TP (pratique pour les apprenants si le dépôt est public).
